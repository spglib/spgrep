Spgrep¶

spgrep is a Python package for calculating irreducible representations of space groups and crystallographic point groups from crystal structures or symmetry operations.

Who this is for: Researchers who use crystal symmetry and Python arrays. Start with the quickstart if you are new to representation calculations. The theory pages explain the mathematics separately.

Start a calculation¶

Install the package with Python 3.10 or later:

python -m pip install spgrep

Follow the quickstart to calculate the irreducible representations of rutile at the X point and associate each matrix with a symmetry operation. Then read how spgrep represents symmetry before using your own data. For a source checkout and contributor tools, see development.

Find the guide for your task¶

  • To calculate irreps from operations you already have, use Calculate irreps from primitive symmetry.
  • To construct tensor bases, analyze lattice vibrations, or work with spinors, choose a worked tutorial. You can skip the derivations to run these examples.
  • To understand little groups, real representations, or spinor factor systems, read the theory guide. Start with space-group irreps, then choose the extension your calculation needs.
  • To look up arguments, return arrays, or numerical options, use the API reference. Experienced users can start there.

Supported calculations¶

spgrep enumerates complex irreducible representations, physically irreducible representations over real vector spaces, spinor representations, and spinor co-representations for magnetic symmetry. It also constructs symmetry-adapted bases. See core functions for the supported combinations of input and representation type.

The source repository, documentation site, and PyPI package provide the code, guides, and releases.
